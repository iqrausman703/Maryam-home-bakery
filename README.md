Maryam Home Bakery

1. Project Overview

Maryam Home Bakery is a simple and responsive bakery website created to showcase homemade cakes, brownies, cupcakes, and other bakery products.

2. Features

- Responsive website design
- Bakery product cards
- Product prices and descriptions
- Order Now button with JavaScript interaction
- Contact information

3. Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub

4. Project Structure

maryam-home-bakery/
├── index.html
├── README.md
├── css/
│   └── style.css
├── js/
│   └── script.js
└── images/

5. How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Browse the bakery products and test the Order Now button.
